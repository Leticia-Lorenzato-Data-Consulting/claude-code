# 70 — Resources

Material de referência: artigos, docs, snippets, livros, vídeos.

## O que vai aqui

- Notas de leitura.
- Documentação técnica que você consulta com frequência.
- Snippets de código com explicação.
- Resumos de livros/talks.
- Conteúdo importado de Notion / OneNote / GitHub READMEs.

## O que **não** vai aqui

- Notas sobre pessoas, empresas, projetos — essas têm pasta própria.
- Drafts e ideias em desenvolvimento — esses são Projects ou Areas.

## Subdivisão

Sem subpastas pré-criadas. Conforme volume cresce, criar subpastas por tema (ex: `Engineering/`, `Business/`, `Saúde/`). Mas comece flat — é mais fácil reorganizar depois do que migrar uma estrutura ruim.

## Frontmatter

```yaml
type: resource
source_type: article | video | book | doc | snippet
source_url: 
date_added: YYYY-MM-DD
tags: []
```
