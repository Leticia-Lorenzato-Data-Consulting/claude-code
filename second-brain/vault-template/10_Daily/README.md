# 10 — Daily Notes

Uma nota por dia. Use o template `_meta/templates/daily-note.md`.

## Função

- Log do dia: o que aconteceu, com quem, decisões, observações soltas.
- Hub temporal: a partir do daily você navega para reuniões, pessoas, projetos do dia.
- Captura rápida: pensamentos sem casa imediata caem aqui antes de serem refinados.

## Configuração no Obsidian

Plugin **Daily Notes** (core):

- Date format: `YYYY-MM-DD`
- New file location: `10_Daily/`
- Template file: `_meta/templates/daily-note.md`

Atalho `Cmd/Ctrl+P → Open today's daily note` é útil.
