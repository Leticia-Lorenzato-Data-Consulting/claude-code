# 00 — Inbox

Captura bruta. Tudo entra aqui antes de ser classificado.

**Regra de ouro:** o Inbox tem que ser esvaziado em revisões periódicas (semanal recomendado). Um Inbox cheio é um sinal de que o sistema está te servindo mal.

## O que vai aqui

- Notas rápidas tomadas no celular ou em movimento.
- Conteúdo capturado via clipper (web).
- Saída do sync engine que não conseguiu auto-classificar (entidades ambíguas, fontes novas).
- Sugestões de auto-link e MOCs (relatórios `auto-link-YYYY-MM-DD.md` da Fase 6).

## Processamento

Para cada item, decida:

1. **Acionável?** → vira task em `50_Projects/<projeto>` ou daily note.
2. **Referência?** → vai para `70_Resources/`.
3. **Sobre alguém/empresa?** → vira ou alimenta nota em `30_People/` ou `40_Companies/`.
4. **Lixo?** → deletar.
