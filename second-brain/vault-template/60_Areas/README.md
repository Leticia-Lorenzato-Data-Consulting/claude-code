# 60 — Areas

Áreas contínuas de responsabilidade. **Sem prazo**.

## Exemplos

**Vault Work:**
- Sales / Pré-vendas
- Engineering
- Operations
- Hiring
- Finance

**Vault Personal:**
- Saúde
- Finanças pessoais
- Família
- Carreira
- Hobbies / Aprendizado

## Diferença para Projects

| | Projects | Areas |
|---|---|---|
| Prazo | Tem | Não tem |
| Definição de "pronto" | Sim | Não |
| Exemplo | "Migração Acme" | "Operations" |

Quando uma area gera muito conteúdo, considere extrair partes para Projects de duração definida ou para um MOC em `90_MOCs/`.
